# PMS 3.0.0 — 정식 릴리스 (2026-11-27)

PMS 현장·PMS 대시보드 두 판 체계의 첫 정식 버전입니다.

## 무엇이 들어 있나
- **PMS 현장**: 공정표(P6 XER·MS Project) 분석, 상황판·공정표·리스크·What-if·룩어헤드·PPC·보고서, 월간 점검·확정본, 현장 모드(휴대폰·오프라인 입력)
- **PMS 대시보드**: 전사 포트폴리오, 이슈 보드(자동 판정·자동 해결), 주간 브리핑, 포트폴리오 질문, 게시 현황
- **현장 ↔ 대시보드**: 게시(판 번호·편집 소유권), 구독·공유 코드·.pms 파일, 리스크·제약 양방향 동기화, 대시보드 이슈·코멘트를 현장 상황판에서
- **AI**: 서버의 Claude CLI로 실행(API 키 없음), 프로젝트별 AI 금지
- **사용자 매뉴얼**: 프로그램 안(학습 센터 → 사용자 매뉴얼, 인쇄·PDF)과 PDF 첨부

## 2.x에서 바뀌는 점
- 상태(정상·주의·위험)는 여유 기준과 이슈 규칙 중 더 나쁜 쪽 하나로 표시합니다. 일부 프로젝트가 "주의·위험"으로 바뀌어 보일 수 있고, 상황판에 이유가 함께 나옵니다.
- 새 비밀번호 규칙: 10자 이상, 영문·숫자·기호 중 2가지 이상(기존 비밀번호는 그대로 사용).
- 조회 계정은 프로젝트 멤버가 될 수 없고 대시보드에 게시할 수 없습니다.
- 대시보드의 최신 판보다 이전 Data Date는 게시되지 않습니다.
- 휴대폰에서 도움말은 작업 ▾ → 이 화면 사용법에 있습니다.

## 업데이트 방법
1. **사내 서버(PMS 대시보드)를 먼저** 업데이트합니다: 시작 스크립트를 다시 실행하면 자동으로 확인·적용합니다(DB는 data/backups 에 자동 백업).
2. 현장 PC는 다음 실행 때 자동으로 업데이트됩니다.
3. 문제가 있으면 관리 → 버전·업데이트 → 되돌리기(또는 `python -m app.updater rollback`).

## 검증
- 단위 테스트 80개, 화면(E2E) 테스트 전체 통과, 자동 접근성 검사(axe) 위반 0건
- 클로즈드 테스트 4갈래(현장 PM 업무·현장↔대시보드 협업·보안·휴대폰/접근성) 결함 수정
- 1.6.0 / 2.0.0 / 2.5.0 데이터 업그레이드, 2.5.0 설치본 자동 업데이트·되돌리기, 새 PC 설치 확인

## 알려진 한계
- 현장 모드 오프라인 입력은 앱을 열어 둔 상태에서만 됩니다(오프라인 새로 고침 미지원).
- 리스크·제약 동기화의 "나중에 고친 쪽 우선"은 PC 시계 기준입니다(사내 시간 동기화 필요).
- 약속(PPC)은 게시한 현장 기준으로만 맞춥니다.
- Docker 이미지는 이번 릴리스에서 빌드 검증을 하지 못했습니다(운영 전 확인 필요).
- 보류 중(별도 승인 필요): 외부 RFI·제출물 연동, 정기 메일 발송, SSO.
