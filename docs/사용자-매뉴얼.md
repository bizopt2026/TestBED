# PMS 사용자 매뉴얼

버전 2.8.0 · 대상: 현장 공무·공정 담당자, 본사 PM팀, 관리자

PMS는 Primavera P6·MS Project 공정표를 올려 공정 현황을 분석하고, 현장과 본사가 같은 숫자로 이야기하게 해 주는 공정관리 프로그램입니다. 프로그램 안의 **학습 센터**(왼쪽 메뉴)에서 이 매뉴얼의 대부분을 따라 하며 배울 수 있고, 이 매뉴얼도 **학습 센터 → 사용자 매뉴얼**에서 바로 보고 인쇄(PDF 저장)할 수 있습니다.

---

## 1. PMS의 두 가지 판

| | **PMS 현장** | **PMS 대시보드** |
|---|---|---|
| 누가 | 현장 공무·공정 담당자 | 본사 PM팀·경영진, 관리자 |
| 어디에 | 각자의 PC | 사내 서버 한 대 |
| 무엇을 | 내 프로젝트 공정표 분석·입력·보고 | 전사 프로젝트 현황, 이슈, 브리핑 |
| 주소 | `http://localhost:8000` | 예: `http://pms-server:8100` |

현장 PC는 대시보드에 **연결**해 프로젝트를 **게시**하고, 본사는 대시보드에서 전사 현황과 이슈를 봅니다. 대시보드 없이 PMS 현장만 써도 됩니다.

## 2. 화면 구성

- **머리글(맨 위)**: 프로그램 이름, 화면 위치, **검색(Ctrl+K)**, 알림 종, 도움말(?), 내 계정 메뉴, **공정표 올리기 ▾**
- **왼쪽 메뉴**: 홈, 보고서 센터, 프로젝트 권한, 학습 센터, 관리(관리자만). 프로젝트를 열면 그 프로젝트의 화면 목록이 함께 나옵니다. 자주 안 쓰는 화면은 **더보기**에 접혀 있습니다.
- **휴대폰**: 왼쪽 메뉴는 ☰ 단추로 열고, 프로젝트 화면 그룹은 아래쪽 막대에 있습니다. 도움말은 **작업 ▾ → 이 화면 사용법**에 있습니다.

### 단축키

| 키 | 동작 |
|---|---|
| Ctrl+K | 프로젝트·화면·작업·명령 검색 |
| ? | 단축키 목록 |
| g 다음 h / o / t / g / c / q / a / r / m / l / w / p / s | 홈 / 상황판 / 타임라인 / 공정표 / 주공정 / 건전성 / 업데이트 분석 / 리스크 / 만회안 / 룩어헤드 / 월간 점검 / 보고서 센터 / 설정 |
| Alt+A | AI 어시스턴트 |
| Esc | 대화상자·메뉴·상세 패널 닫기 |

## 3. 시작하기

### 3.1 로그인
관리자가 계정을 만들었다면 처음에 로그인 창이 나옵니다. 혼자 쓰는 PC에 계정이 없으면 로그인 없이 바로 시작합니다.

- 비밀번호는 **10자 이상**, 영문·숫자·기호 중 **2가지 이상**을 섞어야 합니다.
- 5번 틀리면 그 PC에서 10분 동안 로그인할 수 없습니다.

### 3.2 계정의 권한

| 역할 | 할 수 있는 일 |
|---|---|
| **조회** | 모든 프로젝트 보기, What-if 계산, 보고서 받기, 코멘트 |
| **편집** | 위 + 공정표 올리기, 리스크·제약·약속 입력 (멤버인 프로젝트만) |
| **관리자** | 위 + 사용자·기준·AI 정책·백업 등 관리 |

프로젝트마다 **소유자**와 **멤버**가 있습니다. 읽기는 누구나, 쓰기는 그 프로젝트의 소유자·멤버만 합니다. 멤버가 아닌 프로젝트를 고치려면 프로젝트 머리의 **편집 권한 요청**을 누르세요(조회 계정은 관리자에게 편집자 권한부터 요청).

### 3.3 첫 공정표 올리기
1. 머리글의 **공정표 올리기**를 누릅니다.
2. 파일을 끌어다 놓거나 눌러서 고릅니다: `.xer`(Primavera P6), `.mpp`·`.xml`·`.mpx`(MS Project), P6 XML.
3. 메모(예: "3월 월간 업데이트")를 적고 **올리고 분석**.

매달 같은 프로젝트 이름의 공정표를 올리면 **업데이트 이력**으로 쌓이고, 직전 업데이트와 비교됩니다.

**공정표 올리기 ▾** 에서 다른 방법도 고를 수 있습니다: PMS 파일·텍스트 가져오기, 대시보드에서 찾기, 새 공정표 만들기.

## 4. 홈

- **요약 띠**: 프로젝트 상태 분포, 평균 건전성, 열린 리스크, 월간 점검 완료, 가장 빠른 준공
- **포트폴리오**: 카드 또는 **표**로 볼 수 있습니다(오른쪽 위 카드/표). 상태·정렬로 걸러 봅니다. PMS 대시보드는 표가 기본입니다.
- **할 일 함**: 내게 배정된 일, 프로젝트 경고, 알림

### 4.1 상태(정상·주의·위험)는 어떻게 정해지나
상태는 화면 어디서나 **하나**입니다(상황판, 홈 카드·표, 요약, 이슈 보드가 같은 값).

- **상태 기준**: 목표 대비 여유, 건전성 점수, SPI, 직전 대비 준공 지연 (설정 → 상태 기준)
- **이슈 규칙**: 준공 지연, 직전 대비 7일 이상 악화, 음수 여유, 마일스톤 계획 대비 +14일, SPI 0.8 미만, 기한 지난 제약 등

둘 중 **더 나쁜 쪽**이 상태가 되고, 상황판 상태 줄에 **이유**가 함께 표시됩니다.

## 5. 프로젝트 화면

프로젝트 머리에는 **업데이트 선택(DD)**, **보기 설정**(비교 기준), **작업 ▾**(공유·도구), AI 단추가 있습니다. Data Date가 35일 넘게 지나면 "업데이트 필요" 표시가 나옵니다.

### 5.1 현황
- **개요(상황판)**: 한 줄 상황(예상 준공·직전 대비·주원인), 상태와 이유, 핵심 지표 4개(준공·여유·SPI·건전성 — **지표 고르기**로 바꿈), 이번 주 할 일, 마일스톤, 데이터 준비도, 팀 코멘트. 지표의 **왜?** 를 누르면 숫자의 근거가 나옵니다.
- **타임라인**: 월별 업데이트, 점검, 코멘트, 출력물, 확정본 이력
- **공정표(간트)**
  - 한 줄 도구: 검색, 주공정만, 완료 제외, 배율, 오늘
  - **보기 옵션**: 저장된 보기·열 설정·묶기·전체 맞춤·날짜 이동 / 베이스라인·계획 표시·최장경로 관계선·비교 겹쳐보기·바뀐 작업만·경로 추적 / 끌어서 What-if·A3 인쇄
  - 행을 누르면 아래에 선·후행이, **작업 이름**을 누르면(또는 Enter) 상세 패널이 열립니다.
  - 키보드: ↑↓ 선택, Enter 상세, +/- 확대·축소, T 오늘
- **주공정**, **S-Curve**, **베이스라인·EVM**, **자원**

### 5.2 품질·진단
- **건전성·DCMA**: DCMA 14개 점검 항목과 점수
- **업데이트 분석**: 직전 대비 무엇이 바뀌었고 준공이 왜 밀렸는지
- **P6 일정 비교**, **국내 기준**, **관계 추천**

### 5.3 리스크·대응
- **리스크·예측**: 리스크 등록(확률·영향 최소/보통/최대·대응·담당), 표에서 바로 고치기, 몬테카를로 예측. 영향(일)은 최소 ≤ 보통 ≤ 최대로 입력합니다.
- **자동 만회안**: 목표 일수를 넣으면 공기 단축·병행 후보를 계산합니다(원본은 그대로).
- **What-if**: 공기·진도·관계를 바꿔 준공 영향을 계산합니다. 순환 관계가 생기는 변경은 거부됩니다. 결과는 시나리오로 저장하거나 수정 XER로 받을 수 있습니다.

### 5.4 현장·보고
- **룩어헤드·PPC**: 앞으로 몇 주 작업, 제약(자재·인력·도면 등) 등록, 이번 주 **약속** 등록과 완료 체크 → 주간 **PPC**(약속 이행률). 엑셀에서 복사해 **일괄 입력**할 수 있습니다.
- **작업일보 진도**, **월간 보고서**, **공종 분류**, **벤치마크**
- **보고서 센터**: Word 보고서, 엑셀 리포트(회사 양식 템플릿 가능), A3 공정표, CSV, 보고 패키지(zip)

### 5.5 설정(프로젝트)
일정 계산 옵션, 날씨 휴무일, **상태 기준**(지금 적용 중인 값이 함께 표시됨). 전사 기본 기준은 관리자만 바꿉니다.

## 6. 월간 점검과 확정본

매달 업데이트를 올린 뒤 **월간 점검**(왼쪽 메뉴, 또는 상황판의 "월간 업데이트 점검 열기")을 6단계로 확인합니다. 모두 확인하면 **확정본**을 만들 수 있고, 확정본은 바꾸거나 지울 수 없습니다(보고서 센터에서 받기).

## 7. 함께 쓰기

- **코멘트**: 상황판·작업 상세·리스크에 코멘트. `@아이디`로 부르면 그 사람에게 알림이 갑니다.
- **담당자·기한**: 리스크·제약에 지정하면 그 사람의 **할 일 함**에 나옵니다.
- **동시 편집**: 다른 사람이 먼저 고친 항목을 저장하면 "먼저 수정했습니다" 안내가 나오고, 덮어쓸지 최신 내용을 불러올지 고릅니다.
- **되돌리기**: 리스크·제약·약속·업로드를 지우면 화면 아래에 10초 동안 **되돌리기** 단추가 나옵니다. 놓쳤다면 관리자가 휴지통(7일 보관)에서 복원합니다.

## 8. 현장 모드(휴대폰)

현장에서 휴대폰으로 `#/field/...` 화면(프로젝트 작업 ▾ → **현장 모드**)을 엽니다.

- **이번 주 약속**, **제약**, **작업일보** 탭과 큰 단추
- 📷 단추로 사진을 찍어 작업에 붙입니다.
- **오프라인**: 연결이 끊겨도 마지막으로 받은 작업 목록으로 계속 입력하고, 입력은 휴대폰에 임시 저장했다가 연결되면 자동으로 보냅니다. 위쪽 상태 줄에 "보내지 않은 기록 N건"이 보입니다.
  - 주의: 앱을 **열어 둔 상태**에서 끊긴 경우에만 됩니다. 오프라인 상태에서 새로 고침하면 화면이 열리지 않습니다.

## 9. PMS 현장 ↔ PMS 대시보드

### 9.1 연결
**내 설정 → PMS 대시보드 연결**에서 대시보드 주소와 **대시보드 계정**으로 한 번 연결합니다. 비밀번호는 저장하지 않고 이 PC 전용 연결 정보만 보관합니다. 연결이 끊기면(관리자가 끊었거나 만료) "다시 연결하세요" 안내가 나옵니다.

### 9.2 게시
프로젝트 **작업 ▾ → PMS 대시보드에 게시**.
- 대시보드가 **판 번호**(v1, v2 …)를 매기고 바꿀 수 없게 보관합니다.
- 한 프로젝트는 **한 PC만** 게시합니다(편집 소유권). 같은 PC에서 다시 연결해도 소유권은 유지되고, 다른 PC에서 게시하려면 소유권을 **가져오기** 합니다.
- 대시보드의 최신 판보다 **이전 Data Date**는 게시할 수 없습니다.
- 조회 계정은 게시할 수 없습니다.

### 9.3 다른 현장의 프로젝트 보기(참조 프로젝트)
- **대시보드에서 찾기 → 구독**: 새 판이 게시될 때마다 10분 안에 자동으로 받습니다.
- **공유 코드**(`PMS-XXXX-XXXX`): 게시한 사람이 **작업 ▾ → 공유 코드**로 만들고(기간 1~30일, 횟수, 받는 사람 지정), 같은 메뉴에서 목록을 보고 **취소**할 수 있습니다.
- **.pms 파일·붙여넣기 텍스트**: 대시보드 없이 메일·메신저로 주고받습니다(텍스트는 1MB 이하).

받은 프로젝트는 **참조 프로젝트**(이름 뒤 "· 참조")로, 읽기 전용입니다. 고치려면 **내 프로젝트로 복제**하세요.

### 9.4 리스크·제약은 양쪽에서
현장과 대시보드 어느 쪽에서 고쳐도 10분마다·게시 직전에 서로 맞춰집니다. 같은 항목을 양쪽에서 고치면 **나중에 고친 쪽**으로 맞추고, 밀린 내용은 상황판의 **리스크·제약 동기화 기록**에서 **되살리기** 할 수 있습니다. (약속·PPC는 게시한 현장 기준입니다.)

### 9.5 대시보드 이슈·코멘트를 현장에서
현장 상황판의 **PMS 대시보드** 패널에 대시보드가 찾은 이슈와 코멘트가 보이고, 답글을 남길 수 있습니다. 대시보드에 닿지 않을 때 남긴 코멘트는 임시 저장했다가 자동으로 보냅니다.

## 10. PMS 대시보드(본사)

- **대시보드 홈**: 이슈 요약(위험·주의·새로), **이번 주 브리핑**, **포트폴리오 질문**(예: "이번 달 마일스톤이 위험한 현장은?"), 포트폴리오 표, 게시 현황
- **이슈**(왼쪽 메뉴): 게시할 때마다 규칙으로 찾은 공정 문제. 상태(새로·확인·조치 중·해결)와 담당을 정하고 메모를 남기면 이력이 쌓입니다. 조건이 풀리면 **자동으로 해결**됩니다. 이슈마다 **AI 원인·조치**를 볼 수 있습니다.
- 프로젝트를 열면 현장과 같은 분석 화면을 봅니다.

## 11. AI 기능

AI는 서버(또는 이 PC)에 설치된 Claude CLI로 실행합니다. 대시보드에 연결된 현장의 AI는 **대시보드 서버에서** 실행되고, 관리자가 **AI 금지**로 지정한 프로젝트에는 AI를 쓰지 않습니다.

- 지표 **왜? → AI로 자세히**, AI 어시스턴트(Alt+A), 문서에서 리스크 찾기, 이슈 원인·조치, 주간 브리핑, 포트폴리오 질문
- AI가 꺼져 있으면 규칙 기반 결과(브리핑 등)만 나옵니다. AI 결과는 확인 후 활용하세요.

## 14. 자주 묻는 질문

**Q. 상황판은 '주의'인데 이유가 '상태 기준 미달'이라고만 나옵니다.**
프로젝트 설정 → 상태 기준에서 지금 적용 중인 값(목표 대비 여유·건전성·SPI)을 확인하세요.

**Q. 단추를 눌렀더니 "권한이 없습니다"가 나옵니다.**
멤버가 아닌 프로젝트이거나 조회 계정입니다. 프로젝트 머리의 편집 권한 요청을 쓰세요.

**Q. 게시했더니 "다른 PC가 편집 소유권을 가지고 있습니다".**
다른 PC에서 마지막으로 게시했습니다. 게시 대화상자에서 소유권을 가져오세요(소유자·관리자).

**Q. 대시보드에 연결이 안 됩니다.**
주소(`http://` 포함, 포트까지), 대시보드 계정, 사내망 연결을 확인하고, 관리자에게 서버가 켜져 있는지 물어보세요.

**Q. .mpp 파일이 안 올라갑니다.**
.mpp는 Java 17 이상이 설치된 PC에서만 읽습니다. MS Project에서 XML로 저장해 올리면 Java 없이도 됩니다.

**Q. 실수로 지웠습니다.**
지운 직후 10초 동안 나오는 **되돌리기**를 누르세요. 놓쳤다면 7일 안에 관리자가 휴지통에서 복원합니다. 그보다 오래됐다면 관리자가 백업에서 복구합니다.

## 15. 용어

| 용어 | 뜻 |
|---|---|
| Data Date(DD) | 공정표의 진도 기준일 |
| 여유(TF) | 준공을 늦추지 않고 밀릴 수 있는 일수. 음수면 이미 늦음 |
| 주공정·최장경로 | 준공을 결정하는 작업 사슬 |
| SPI | 계획 대비 실적 진척 비율(1 미만이면 늦음) |
| DCMA 14 | 공정표 품질 점검 14개 항목 |
| PPC | 주간 약속 이행률 |
| 베이스라인 | 비교 기준으로 저장한 계획 |
| 게시·판 | 대시보드에 올린 공정표와 그 번호 |
| 참조 프로젝트 | 다른 현장에서 받아 온 읽기 전용 프로젝트 |
