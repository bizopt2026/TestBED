# 화면 코드 구조 (static/)

빌드 없이 브라우저가 바로 읽는 일반 스크립트입니다. `index.html`의 순서대로 `defer`로 읽히며, **뒤 파일이 앞 파일의 함수를 감싸거나 바꿉니다**(예: `showProject = async function …`). 함수 이름으로 서로 부르므로, 바꾼 함수는 그 이후 모든 곳에 적용됩니다.

| 파일 | 내용 |
|---|---|
| `app.js` | 기본: `api()`·라우팅(`route`)·대부분의 탭 화면(공정표 `tabGantt`, What-if, 리스크, 룩어헤드 …) |
| `ui.js` | 공통 UI: 대화창(`ui.form/confirm/notice`), 서랍, 작업 상세, 용어 도움말, 테마, 단축키 |
| `ui2.js` | 상단 바, 알림, Ctrl+K 팔레트, 표 기능(정렬·필터·내보내기), SVG 차트(`chartSvg`) |
| `field.js` | 현장 모드(휴대폰), 오프라인 임시 저장 |
| `learn.js` | 학습 센터, 따라하기(투어), 화면별 도움말 |
| `reports.js` | 보고서 센터(엑셀 양식) |
| `app2.js` | 4차: 상황판 기초, 데이터 준비도, 월간 점검 마법사 기초 |
| `app3.js` | 5·6차: 프로젝트 머리글·탭, 홈, 설정 하위 탭, 코멘트, 일괄 입력, 사용자 설정 |
| `app4.js` | 6차: 할 일 함, 타임라인, 보고 패키지·확정본, 오류 화면, 단축키, 관리자 사용 현황·업데이트 |
| `app5.js` | 7차 디자인: 아이콘 세트, 사이드바, 로그인 화면, 차트 팔레트, 표 간격, 디자인 가이드 |
| `app6.js` | 8차: 새로 바뀐 점, Ctrl+K 명령, 역할별 홈·마일스톤 공정표, 내 설정, 비교 화면, 차트 클릭, 바탕화면 알림, 로고 |
| `style.css` → `theme.css` | 기본 스타일 위에 디자인 기준값(theme)을 덮어씀. 새 스타일은 `theme.css`에만 추가 |

## 규칙
- 색·간격은 `theme.css`의 기준값(`var(--accent)`, `var(--crit-text)` …)만 씁니다. 화면 코드에 `style="…"`를 새로 넣지 말고 유틸리티 클래스(`between`, `mt0`, `fs12` …)를 씁니다.
- 새 화면은 `#/design`(디자인 가이드)의 부품을 그대로 씁니다.
- 화면을 바꾸면 `tests/e2e/run.js`(기능·접근성·기준 이미지)를 돌립니다. 의도한 디자인 변경이면 `E2E_UPDATE_BASELINE=1`로 기준 이미지를 갱신합니다.
